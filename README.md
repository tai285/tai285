## ✦ Hi, I'm Dorothy

I'm interested in building systems where **software meets the physical world** and where AI can turn system data into something genuinely useful.

My work began with an **IoT-based Final Year Project** involving RFID, ESP32, embedded systems, and software. After receiving recognition at **PRISM 2026**, I extended the project into research by introducing **AI, Large Language Model implementation, and AI tool calling**.
